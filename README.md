# 📱 Social Media Content Generator

An AI-powered web application that automatically generates engaging social media content from YouTube video transcripts.

The application extracts the transcript of a YouTube video and uses an AI agent powered by Google Gemini to generate platform-specific content for LinkedIn, Instagram, and Twitter.

🔗 **Streamlit App:** YOUR_STREAMLIT_APP_URL

## 📌 Features

- 🎥 Extract transcripts directly from YouTube videos
- 🤖 AI-powered content generation using Google Gemini
- 🧠 Agent-based content generation using OpenAI Agents SDK
- 📱 Generate platform-specific social media posts
- 💼 LinkedIn post generation
- 📸 Instagram caption generation
- 🐦 Twitter/X post generation
- ✍️ Custom user prompts for controlling generated content
- 📥 Download generated posts as text files
- 🌐 Streamlit-based interactive web interface
